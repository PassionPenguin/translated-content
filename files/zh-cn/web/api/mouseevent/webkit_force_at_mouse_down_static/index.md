{{APIRef("Force Touch Events")}}{{Non-standard_header}}

**`MouseEvent.WEBKIT_FORCE_AT_MOUSE_DOWN`** 是一个专有的 WebKit 特有静态数值属性，值为正常点击所需的最小力度。

由于 `WEBKIT_FORCE_AT_MOUSE_DOWN` 是 `MouseEvent` 的静态属性，因此你始终以 `MouseEvent.WEBKIT_FORCE_AT_MOUSE_DOWN` 的形式使用它，而非作为 `MouseEvent` 实例的属性那样去使用。

## 规范

*不属于任何规范。*Apple 在 [Mac Developer Library 上提供了描述](https://developer.apple.com/library/archive/documentation/AppleApplications/Conceptual/SafariJSProgTopics/RespondingtoForceTouchEventsfromJavaScript.html)。
